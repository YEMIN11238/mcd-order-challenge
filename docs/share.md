# 作品介绍与演示

## 简介

这单，你会怎么点？麦麦点餐挑战把官方麦当劳 MCP 的真实菜单与核价记录做成五道手机单选题。预算、必须保留的小食、升杯差额、跨店价差、条件优惠，每选完一题就揭晓解析和证据。免登录，约两分钟，答完生成成绩卡，邀请饭搭子挑战同一套题。

题目使用 2026-10-20、2026-10-23 的历史实测数据，非实时查价，不下单。新增案例明确使用测试预约 12:00 的菜单与核价。17 条业务记录、7 次核价均可查看请求、金额、采集时间与 traceId。

## 约 30 秒演示

1. 手机打开首页，点「开始挑战」，展示无需登录。
2. 在预算题选一项，点确认，展示解释与「查看这题的真实数据」。
3. 展开一条证据，指明日期、金额和 traceId 可以回溯。
4. 完成其余四题，在结果页展开错题复盘。
5. 点「保存成绩卡 PNG」，展示实际生成的图片与同题链接。

不要把题库的历史金额说成当前售价，也不使用虚构用户数、胜率或排名。
